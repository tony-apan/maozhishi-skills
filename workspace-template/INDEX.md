# 工作区总索引

找东西先看这里。一个工作区、一套备份地记录（主备份与镜像两介质，只办一处时按实际登记的一处）；内部按模块分区，模块分区列序固定：memory 第一、laifaxin 第二、allincms 第三，其余注册分区按登记先后、misc 垫底（根共用区目录 00-inbox／10-sources／20-knowledge／90-handover 在下表列于首部，不入此列序）。

| 分区 | 放什么 |
| --- | --- |
| `00-inbox/`、`10-sources/` | 整仓共用：收件、来源登记 |
| `20-knowledge/` | 整仓共用：公司档案、产品事实、卖点与已定口径 |
| `90-handover/` | 整仓交接（模块交接在各自分区里） |
| `memory/` | 记忆：用户档案、已定口径、业务记忆、未完成事项 |
| `laifaxin/` | 来发信：计划、日报、信稿、台账与开发状态 |
| `allincms/` | 建站：计划、文章原稿、发布与站点记录 |
| `b2b/` | B2B 平台背书：平台注册进度与情况台账 |
| `misc/` | 杂项与待问区（待问区只存本地） |

新模块开工时自动登记新分区（英文小写短横线名、不重名），登记后在本表加一行。

## 备份地记录

（本段是设置页备份两行与办理状态的人读记录，90 交接层放同内容镜像；字段与备份地索引 `maozhishi-backup.json` 的 locations 对齐。与设置页对不上时以设置页为准并回写对齐；本地记录与备份地索引对不上时先对账：登记与办理状态以设置页为准、已实际存入的快照与文件以备份地索引为准，按此重建本地记录。）

- 状态：已登记 / 未定（未办时下面两行介质记「未定」；与备份模块第十八节五档的对应：未定＝未登记，已登记后按办理进度取已登记未办／部分完成／已办／权限异常停写等档，取值以五档为准）
- 定于：<日期>（经备份模块办理流程定；开工链最低备份步办理或事后补办均可）；未定时本行记「未定」
- 主备份介质：未定（办好后记介质与账号标识：如 GitHub 私有仓 `maozhishi-backup`，账号标识 <GitHub 登录名>，仓地址 <URL>；手动导出形态记导出目录）
- 镜像介质：未定（办好后记：如 Google 云盘文件夹 `maozhishi-backup`，账号标识 <Google 邮箱>，文件夹 ID <ID>，路径 <人读路径>；不办镜像记「无」）
- 备份授权档位：整份 / 仅关键清单 / 暂不备份（用户 <日期> 定）
- 台账进备份：是（用户 <日期> 明确同意）/ 否（只备公司级状态）；授权档位为暂不备份时本行记「不适用（暂不备份）」
- 两行一致性：授权档位非整份时台账本体不进备份、本行只能记「否」或「不适用」；填出矛盾组合的，以备份模块第八节（同意三档与台账三条件）的定义为准、当场改正再继续
- 首次全量同步：<日期时间>，快照号 <seq>
- 最近同步：<日期时间>，状态 <按备份模块五档取值，主备份与镜像分开记>
- 备份排除清单：<名称逐行列，或写「无」>
