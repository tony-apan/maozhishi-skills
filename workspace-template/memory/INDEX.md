# memory 记忆 · 索引

这里是 AI 对你的长期记忆：只存结论与要点，不存流水账；你确认了新事实、新口径、新决定，当轮就回落到这里。

| 文件 | 放什么 |
| --- | --- |
| `user-profile.md` | 用户档案：称呼、时区、业务与偏好 |
| `decisions.md` | 已定口径与重要决定（带日期与出处） |
| `open-items.md` | 未完成事项清单 |
| `topics/` | 分主题业务记忆，一主题一文件，入口看 `topics/INDEX.md` |

红线：联系方式明细、凭据、聊天与邮件原文永不进这里。你随时可以查、可以删：问「你记住了我什么」会如实列出，说删哪条就删哪条。
本分区在备份里排第一：换账号时先拉这里「回血」，再拉业务数据。
