# 用户本地工作区模板（workspace-template）

这是给每位使用者建「本地真源」的起点：把整个目录复制到你自己的电脑/工作区，改名为你的工作区即可。所有模块（建站、获客、B2B、社媒、广告）都只往这里读写资料，不散落在聊天记录里。

## 七层骨架（与建站 SKILL §3 同一套）

| 层 | 放什么 |
| --- | --- |
| `00-inbox/` 收件 | 用户给的一切原始资料先进这里（PDF/PPT/Word/图片/链接清单），未整理不引用 |
| `10-sources/` 来源登记 | 每份资料登记来源、日期、可信度；渠道原文（邮件/聊天提炼）剥离个人信息后登记 |
| `20-knowledge/` 知识底稿 | **资料库核心**：公司档案、产品事实底稿、素材索引——各模块取数只认这里确认过的事实 |
| `30-tasks/` 任务清单 | 在跑任务、排期、待确认清单 |
| `40-output/` 产出 | 文章原稿主本、开发信存档、帖文稿（主本在此，发布/存档都是副本） |
| `50-data/` 数据 | 台账与数据：找客台账镜像、发送记录、每日数据（Google 表格只是展示层，真源在此） |
| `90-handover/` 交接 | 交接文件：进度、卡点、待办；中断后照它续接，不凭记忆 |

每层有一个 `INDEX.md` 写清这层放什么、入口文件是哪个；找东西先看索引。

## 资料库四格与七层的对应

- 公司档案 → `20-knowledge/company-profile.md`（模板已备）
- 产品事实底稿 → `20-knowledge/产品事实底稿-<产品名>.md`（一产品一档，模板已备）
- 素材库 → 原文件放 `00-inbox/` 或云盘，索引记在 `20-knowledge/asset-index.md`
- 数据与台账 → `50-data/`

## 同步与安全

- 整个工作区同步进你本人专属的私有仓或云盘（换设备、换 Muse 账号靠它衔接）。
- 密码、客户个人信息永不进本工作区、不进任何仓；凭据只走 Muse 密码库。
- 新资料先入格、再被引用；库里没有的信息，Muse 必须显名说缺，不许猜、不许编。
