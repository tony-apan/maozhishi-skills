# laifaxin 来发信 · 索引

来发信模块的工作区。分区内沿用 30/40/50/90 分层：

| 目录 | 放什么 |
| --- | --- |
| `30-tasks/` | 计划与排期 |
| `40-output/` | 日报、开发信稿 |
| `50-data/` | 台账本体、找客记录、搜索日志、公司去重总账、公司级开发状态 |
| `90-handover/` | 来发信交接 |

两边都要读的公司事实档案不在这里，在根共用区 `20-knowledge/`。本分区整体进备份同步清单（台账本体进备份须经用户明确同意，见备份规格）。
