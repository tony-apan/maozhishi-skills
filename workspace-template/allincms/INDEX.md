# allincms 建站 · 索引

建站模块的工作区。分区内沿用 30/40/50/90 分层：

| 目录 | 放什么 |
| --- | --- |
| `30-tasks/` | 计划与排期 |
| `40-output/` | 文章原稿主本（改文章先改这里，再同步存档与站上） |
| `50-data/` | 发布记录、站点设置记录 |
| `90-handover/` | 建站交接 |

两边都要读的公司事实档案不在这里，在根共用区 `20-knowledge/`。文章存档地与全量备份地是两个概念，不要混（见建站 SKILL）。
