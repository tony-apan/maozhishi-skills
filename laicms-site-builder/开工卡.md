# 开工卡（建站）

开工先按这张卡走完，再干活。细则都在 SKILL.md 里，干哪件事读哪一节。

1. **先核对采纳记录**：查长期记忆里有没有用户亲口确认的采纳记录（选 1 全自动／选 2 每步先问／粘贴确认句按选 1 记）。有，按记录范围继续（选 2 的每类动作先问后做）；没有、查不到、来源不明或与用户后来说法冲突的，一律按没有处理——停下来请用户在对话里二选一，选完记下再继续。
2. **版本核对**：读展示站 skill.maozhishi.com 根目录的 VERSION 和 release-manifest.json（线上发布版），和本地仓根目录的 VERSION 比对；展示站不可达改走 GitHub 公开仓。版本判定只读这两个数据文件——备份、更新要读的其他文件按各自细则读，不受这一句限制。
3. **有新版再更新**：先备份旧版技能文件（整份拷到仓根目录 backup/<旧版本号>/ 下，重名加日期后缀、不覆盖旧备份；这份备份与工作区无关、没有工作区也要备），再走三查：① 权限变化先报后换——逐文件比对新旧实际文本，涉及授权、自检、更新机制、发送或发布权限的段落有改动，整体暂停、先报用户确认再换；② 双源核对——展示站与公开仓版本号一致、且本站索引登记的压缩包摘要与公开仓同版实算摘要一致才换；只有一个来源可达时，可按该来源换装，但报告里必须写明这次只核了一个来源；③ 两边同版但内容对不上，按异常停下报告、不替换。三查都过再换装，换完重新读一遍新版说明。
4. **逐项汇报**：向用户报——当前版本与采纳状态、备份在哪与更新结果、站点项目现状一句话、卡住或待你决定的事、今天要推进的下一步。
