# 网站风格档案（双轨对照）

建站开工时让用户在两种网站风格里选一轨，全站按所选轨施工与评审（选择机制、默认值与记录要求见 SKILL 第二节「定网站风格」）。**默认轨为外贸 B 端**；用户选跨境 C 端时整站切 C 端轨。两轨不许混搭：一站只有一轨，页面与页面的口径打架按混搭扣分（判据见 references/beauty-review.md「风格定位（加审项）」）。

## 平台共同底座（两轨都受约束，先认清再谈风格）

以下为平台实测事实（出处：references/laicms-模块标准库.md），风格只能在这些事实里做文章，不许虚构平台能力：

- **产品详情模板没有价格与购买区块**（标准库 §4.4、§六第 7 条）：两轨都不许假装有价格区、购物车或购买按钮；购买引导一律靠正文行动段＋页眉报价按钮＋询盘弹窗（Contact Dialog Form，标准库 §三 Forms 组）＋联系模块承接。平台没有站内下单、结算与在线支付，任何一轨都不许写「在线支付」「立即下单」类话术。
- **个别模块有 Price Label 展示位**（如主推区，标准库 Heroes／Products 两组口径）：只许填规格口径（如「750 ml / 25 oz」）或用户真实价格作展示，不编价格；不用就显式留空——留空不处理平台会回填演示价格。
- **主题层两轨同界**：仅 1 套 Default 主题；颜色 token、圆角、全局间距基准、阴影、字体族与字距可改，字号不可调、逐模块间距不可调（标准库 §一、§六）。风格差异靠选色、选图、模块组合与文案实现，不靠不存在的开关。
- **事实纪律两轨同守**：只用产品事实底稿里已确认的事实，价格、认证、销量、评价、交期、售后承诺没有来源一律不写；演示内容与模板话术（包邮、退货承诺等）不许借用，清零口径见 SKILL 残留词清单。

## 双轨对照（逐项执行，不许只取一半）

### 1. 定位与受众

- **B 端轨**：卖给海外批发买手、零售商采购、经销商与品牌方的采购决策人。对方一次买一批、会复购，决策看参数、合作条款与供货稳定性，站的任务是让采购在几分钟内完成甄别并发出询盘。
- **C 端轨**：卖给海外个人消费者。对方买一件自己用，决策看场景代入、单品亮点与真实口碑，站的任务是让消费者看懂、喜欢、敢问价。

### 2. 视觉基调

- **B 端轨**：选色走深色系沉稳主色（深蓝、松绿、炭灰一类），低饱和，同屏彩色受控（1 主色＋1 辅色＋1 强调色＋灰阶）；图片以产品白底图、规格细节图、工厂／仓库／包装这类能当证据的实拍感图为主；排版密度高——规格表、参数行、条款块排得满而整齐，买家是来查资料的，信息优先于留白。
- **C 端轨**：选色可用明快鲜明的品牌色，强调色饱和度可以高一档做点缀（促销感只许对应真实活动）；图片以生活场景图、人物使用图、氛围图为主，产品融进场景里讲；排版密度低——留白多、单屏只讲一个卖点、大图大标题，消费者是来逛的，先有感觉再看细节。

### 3. Hero 口径

- **B 端轨**：主标语＝品类＋供货能力（说清给谁供货、供什么货）；副文案给硬口径——起订量、交期、定制能力各一句；按钮主＝Get a Quote、次＝Browse the Catalog。
- **C 端轨**：主标语＝核心单品或核心场景的收益句（用上它生活哪里不一样）；副文案给使用场景与一句能兑现的体验承诺；按钮主＝View the Collection（领到产品列表）、次＝Ask for Price & Shipping。不许写 Buy Now、Add to Cart——平台没有这个功能，写了就是假按钮。

### 4. 产品呈现

- **B 端轨**：参数与批发条款前置——规格表、起订量、样品政策、交期、包装、定制选项放产品页显眼处；正文走三段骨架（适合谁与用在哪／构造与规格／怎么订）；无价格位（模板本就没有，见共同底座）。站级验收另见 SKILL《B2B 合格站要素清单》。
- **C 端轨**：场景与单品卖点前置——先讲用在哪、解决什么、体验如何，规格表退后作下单前核对；卖点只写单品自身的差异点，不写批发条款。价格只许按共同底座的 Price Label 口径处理：有用户真实价格表才标真实价格作展示并注明以询盘确认为准，没有就留空不编价。产品详情页的收尾行动段引导问价与确认库存，不引导「下单」。

### 5. 文案语气

- **B 端轨**：专业、克制、给数据与边界；称呼对方用 buyer、retailer、partner；不煽情、不喊口号、不写生活方式种草句。
- **C 端轨**：亲切、具体、讲感受与场景；用第二人称对消费者说话；可以活泼，但不许编造使用体验、销量与用户评价——体验句只能来自用户提供的真实反馈，没有就写功能与场景、不写「大家都说好」。

### 6. 文章选题与行文

- **B 端轨**：按采购痛点选题——交期、起订量、品控、合规、利润空间、供货稳定，写采购决策里真会卡住的问题；形态以对比、清单、诊断为主，帮采购做决定（细则见 SKILL「写文章的细则」首条）。
- **C 端轨**：按消费场景与使用痛点选题——怎么选、买多大、用在哪、怎么搭配、怎么保养、和同类比差在哪；形态以指南、场景清单、同类对比为主，帮消费者在问价前想清楚。标题可带场景词与人群词，不带起订量、批发这类 B 端交易词（与 SKILL 交易词口径一致：词随轨走）。
- 两轨共同：选题验证、痛点证据、篇幅带与正文深度地板、五段结构与禁编造不分轨，同一套执行。

### 7. CTA 口径

- **B 端轨**：主 CTA 动词用 Get a Quote、Request Samples、Talk to Sales；价值交换＝正式报价、样品包、规格书；购买阶段按 SKILL 五阶段合同收完整询盘信息（买什么、数量、目标市场、时间、贸易条件）。
- **C 端轨**：主 CTA 动词用 Ask for Price & Shipping、Check Availability、Ask a Question；价值交换＝确认总价（含运费）、确认有货、要实拍细节图、问清时效；收资只问到能答复为止（想要哪款、寄到哪个国家、几个），不许按批发口径一上来收一堆贸易条件。
- 两轨共同：一页一个主 CTA、动词必须具体（禁 Learn More、Get Started 类空动词）；转化承接只有询盘弹窗、页眉报价按钮与联系模块这一条真实路径，未实测可达的联系方式不许写进 CTA。

### 8. 页脚与信任元素侧重

- **B 端轨**：信任靠可核验的商业信息——公司一句话定位（首页与关于页一致）、批发条款有处可查（FAQ 必备五题：起订量、样品、交期、定制、付款与物流）、认证与出口能力只写已确认的、响应时限明写；页脚放公司全称、联系邮箱与条款入口。
- **C 端轨**：信任靠消费者关心的保障——真实售后与退换口径（只写用户真实政策，没有就不写这一块）、物流时效写真实值、坏了找谁修要有着落；FAQ 换消费者五问（多少钱含运费、多久能到、能不能退换、坏了怎么办、怎么联系真人），只答真实政策；页脚放联系与售后入口、真实社交账号（没有就留空，不挂平台默认假链接）。
- 两轨共同：联系方式全站只有一种写法；页脚品牌名、描述、版权逐项换成用户自己的，演示字样清零。

## 改选与混搭处理

- 中途改选的复核清单：按本档案八项逐页过——视觉方向句、Hero 文案、产品页呈现顺序、全文语气、文章选题口径、CTA 动词与收资深度、FAQ 与信任元素、页脚信息，逐项按新轨改齐并记进交接，复核没走完不算切换完成（机制见 SKILL 第二节「定网站风格」）。
- 评审时发现单页串轨（如 B 端站出现种草文案、C 端站冒出起订量条款），按 beauty-review.md 风格定位加审项在概念与一致性两维扣分，逐项改回所选轨再复审。
