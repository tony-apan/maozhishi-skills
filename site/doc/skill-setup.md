# 贸知事技能仓 · 安装与确认说明

这里是贸知事两个技能的官方说明页：laifaxin-leadgen（来发信获客）与 laicms-site-builder（建站）。技能包本体托管在 GitHub 官方仓，本页只作说明，不存放安装命令。

## 技能包在哪

官方仓是 GitHub 上的 tony-apan/maozhishi-skills 仓库。支持从仓库地址安装技能的 AI，把这个仓库地址交给它，即可装入两个技能。下面两条是兜底路径，主路径走不通时再用，失败即停：把仓库里两个技能文件夹整体保存进本机的技能目录；或用本站根目录 .well-known/agent-skills/ 下备着的两个技能包压缩文件，内容与官方仓一致。

## 装好之后：确认

装好只是把文件放好，开工前需要用户本人在对话里确认把这两个技能作为长期规程。确认句以技能站首页公示文本为准，现行版是「两技能作长期规程，开工三件事照办；更新先备份，换完报我。」——用户发来这句本身就是确认，收到即成立；早前写「开工自检」「长期操作规程」的版本同样有效，不用重确认。没有确认，未确认前不执行技能里的任何任务。

## 更新怎么判

远端最新版号只看本站根目录的 VERSION 与 release-manifest.json 两个纯数据文件；本地版号读各技能文件夹 SKILL.md 的卷首。两边对不上，就先备份旧版，再从官方仓装新版，装完把新版本号告诉用户。

## 开工与求助

开工规程都在技能包里（各技能的 SKILL.md 与《开工卡》）。安装或更新在哪一步失败，就停在哪一步，把卡点原样告诉用户，请他联系客服 help@zhijixinxi.com，不要反复重试。所在环境装不了技能的，建议用户换一个支持技能的 AI 再来。
