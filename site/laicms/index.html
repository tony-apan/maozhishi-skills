独立站技能 使用教程

小陈做户外用品出口，想建一个英文网站卖给国外的批发商。他不懂代码，也没建过站。这篇带你跟着小陈走一遍全程——全程你只做三件事：回答问题、给资料、看结果点头，剩下的交给 AI。文中截图是一个已建好的户外用品样站，前台后台都是真实的图。

准备 第一步 · 装技能 第二步 · 回答问题给资料 第三步 · AI 施工 第四步 · 验收 第五步 · 上线后 常见问题 进阶四节

开始之前，先准备好三样东西

  1. 一个 AI 助手：比如 Muse。没有的话先看 《先认识 Muse》 注册一个。
  2. 贸知事技能仓：不用你下载，待会儿在技能站首页复制一句话发给 AI，它自己就装好了。
  3. 一个建站平台账号：到 AllinCMS 官网 allincms.com 按指引开通。官网只有一种联系方式——扫码加客服微信、人工开通；拿到账号后，登录入口是 workspace.laicms.com。账号开在你自己名下，建出来的站就是你的。

第一步：把技能仓交给 AI

  1. 打开 技能站首页。
  2. 把首页上那句安装话术原样复制、发给你的 AI 助手。
  3. 发完就等着：AI 会自己读完安装说明，把技能仓装好，然后用大白话告诉你它能帮你做哪几件事，带你从第一件小事开始。需要你提供资料或授权时，它会一次只问你一件事，并说清要什么、用来做什么。

第二步：AI 问你问题，你照实回答

AI 开工之前会先把几件事问清楚，一次问一件，不会一股脑全甩给你。你知道多少就答多少，拿不准的直接说不知道，它会给你建议。

先选一个网站风格（二选一）

  1. 外贸 B 端（默认，推荐）：卖给国外的批发商、经销商、零售店。页面先把起订量、交期、付款方式这些正经条款讲清楚，看着专业、可信。做出口批发的，选这个。
  2. 跨境 C 端：直接卖给国外的普通消费者。页面更活泼，突出好看、好用、生活场景。

小陈卖的是批发，所以他选了外贸 B 端。你拿不准就选外贸 B 端，选错了后面也能改，只是要多花一点时间全站调整。两轨细的区别在篇尾进阶一节。

再把你的真实资料给它

AI 会按下面的清单跟你要，有多少给多少：

  1. 公司叫什么、哪一年成立的、主要做什么产品；
  2. 每个产品的名称、规格（容量、尺寸、重量、材料这些数字）和照片；
  3. 产品怎么分组（比如瓶子一类、包一类）；
  4. 批发规矩：起订量多少、样品怎么寄、交期多久、能不能印客户的标志、怎么付款、怎么发货；
  5. 联系方式：邮箱、电话、公司地址——这些是要放到网站上给买家看的；
  6. 有公司标志（Logo）图片就发给它，没有就直说，它会问你打算怎么办。

一条铁规矩：资料只给真的。你没给的数字，AI 不会替你编——它要么把那一处留空，要么回来问你。所以请别嫌它问得多，它问得越细，网站上的内容就越实在，买家看了才敢下单。

第三步：AI 进后台干活，你等着看样站

资料齐了，AI 就进建站平台的后台开始施工。登录的时候它会请你配合一下（比如把密码存好、确认一次登录），其余操作都不用你管。它大致按这个顺序干：

  1. 进你的站：在后台的站点列表里，找到你的站，点「进入后台」。
  1. 先看仪表盘：一眼能看到站里已经有几个页面、几篇文章、几个产品，做到哪一步心里有数。
  1. 搭框架、排页面：在页面编辑器里，一块一块把首页、产品页、关于我们、联系页拼出来，配色、字体、间距都按规矩配好。
  1. 传产品：把你的产品一个个上架，照片、规格、批发条款都填齐。
  1. 写文章：按国外买家真正关心的事来写——比如怎么挑货、起订量怎么回事、交期怎么安排。文章是写给买家看的，也是写给搜索引擎看的。
  2. 配好「让买家搜得到你」的设置：标题和文章里，用上买家平时会搜的词，这样买家在谷歌、或者问 AI 的时候，才容易找到你的站。这一步 AI 顺手就做了，细的做法在篇尾进阶四节。买家搜得到你，才会有询盘找上门。

样站搭好之后，AI 会把链接发给你。

第四步：你来验收，不满意就说人话

打开 AI 给你的链接，一页一页看：

重点看四件事：

  1. 公司名称、联系方式，对不对；
  2. 产品的规格数字，对不对；
  3. 起订量、交期、付款方式这些规矩，对不对；
  4. 整个站看着顺不顺眼、像不像一家正经做批发的公司。

不满意，不用客气，也不用懂术语，直接说人话就行，比如：「首页第一张图太暗了，换一张亮一点的。」「起订量写错了，我们是 10 箱起订，不是 12 箱。」AI 改完你再看。直到你点头确认，它才会把站正式发布出去。

第五步：上线之后，日常不用你操心

  1. 文章会持续更新：站不是建完就放着，AI 会按约好的节奏接着写文章、传新品，你有新产品随时发给它。
  2. 平台有变化，AI 自己跟上：建站平台改了功能、加了新东西，AI 会自己调整做法，不用你盯着。
  3. 询盘从联系页来：买家在联系页的表单里留言问价，留言会送到开工时约好的地方（比如你的邮箱），你按平时收邮件的习惯处理就行。

常见问题

要懂代码吗？
不用。全程你只做三件事：回答问题、给资料、看结果点头。碰代码的活都是 AI 干。
要会英文吗？
不用你写。网站是英文的，AI 来写、来翻；你要看的地方它会用中文跟你说明白。产品数字、公司名字对不对，你认得出就行。
多久能上线？
资料齐的话，最快当天就能看到样站。样站改到满意再正式上线，一般一两天。
要花什么钱？
两笔：一笔是建站平台的账号费用，以平台官网说的为准；一笔是你用的 AI 助手的费用，按你自己订的套餐。除此之外没有别的收费。
做出来的站归谁？
归你。账号是你自己的、站是你自己的、资料也是你自己的。哪天不想用 AI 了，你自己登录后台，也能接着管这个站。

卡在哪一步，就把这篇教程发给你的 AI，跟它说一句「照着这篇带我走」，它就知道怎么带你了。

进阶四节

下面四节是建站过程中常被问到的四件事，各一小节说清。第一次建站可以先跳过，遇到时回来查。

进阶一 · 建站风格怎么选

开工先选一轨，全站按这一轨做，不混搭。拿不准选默认的外贸 B 端。

外贸 B 端（默认）跨境 C 端
卖给谁海外批发买手、经销商、品牌方采购海外个人消费者
页面感觉沉稳配色，信息排得满而整齐，先给证据再谈感觉明快配色，留白多，大图大标题，先有感觉再看细节
产品页规格表、起订量、样品、交期、包装放显眼处先讲用在哪、体验如何，规格退后作下单前核对
文章写什么采购痛点：交期、起订量、品控、合规消费场景：怎么选、用在哪、怎么保养
按钮叫什么Get a Quote（要报价）、Request Samples（要样品）Ask for Price & Shipping（问总价）、Check Availability（问有货没）

先认清一个平台事实：AllinCMS 的产品页没有价格和购买区块，站内也不能下单、结算、在线支付——两轨都一样，买家最后都通过询盘表单、页眉的报价按钮、联系模块来问价。选错了能改，但要全站逐页过一遍，开工时花一分钟想清楚更省事。

进阶二 · 给网站接 AI

站点本身不带 AI。绑上你自己的大模型 API Key 之后，后台才能用 AI 写产品、写文章、做翻译。费用由模型服务商按用量收，不经建站平台，日常用量通常花费不高。

你只做三件：去模型服务商官网注册账号、小额充值、创建 API Key 并当场存好。其余 AI 代办：进后台「设置 → AI API 配置」选服务商、填四项、测试连接、保存，并把状态读回给你看。

  1. 选模型：默认 DeepSeek，便宜、配置简单；长文档、PDF、表格多时可选 Kimi；英文和复杂任务多可考虑 OpenAI / Claude / Gemini，按已有账号和预算选。
  2. 建 Key：充值后创建。Key 只显示一次，立刻存进你自己的密码管理工具，丢了只能重建。
  3. 填四项：接口地址、API 格式、Key、模型 ID（DeepSeek 日常用 deepseek-chat）——AI 代办，你只管把 Key 通过安全录入卡交给它。
  4. 测试并保存：先测试连接，成功再保存。失败先查 Key 有没有多复制空格、余额够不够。
Key 不要发到聊天里，也不要写进任何文件；交给 AI 只走安全凭据录入卡。另外注意：ChatGPT Plus 这类订阅会员不是 API，绑不了，要用 OpenAI 得去其开放平台单独建 Key。

进阶三 · 要不要开多语言

我们的建议：主站先不开平台多语言。先把英语站做完整、跑出收录和询盘；之后哪个地区有反馈，就为它单独建一个当地语言的独立站——当地语言、当地客户搜的词、当地在意的内容，逐站单独做。原因很简单：平台多语言是整站机翻，参数、品牌名、本地说法容易失真，还要逐语言人工核对；独立站每种语言都是为当地市场单独做的内容，收录和信任都更扎实，一个市场出问题也不牵连其他站。

这是建议，不是拦截：你听完仍要开，AI 会照官方流程完整引导——前置是内容基本完整、AI API 已绑好；然后在后台「设置 → 站点语言」添加语言（只勾真实目标市场），等整站翻译完成（看已翻译／未翻译／翻译失败三个数），不全就补翻，最后逐个语言切到前台验收，参数、品牌名、联系方式逐项人工确认。

进阶四 · SEO 与 GEO 怎么做

SEO 是让搜索引擎找到你，GEO 是让 AI 回答时提到你。很多人觉得难，其实就是两件事：网站持续有实在的新内容，加上每页都按买家提问的方式写清楚。都由 AI 在建站和日更里顺手做，你不用学，也不用逐项打勾验收。

  • 勤更新是主引擎：新产品、新信息、补缺口，不做无意义的改字刷新。
  • 标题和描述认真写：带上买家会搜的核心词，不留平台默认的通用描述。
  • 首段先说清：第一段讲清「这是什么、解决什么痛点、适合什么场景」，搜索引擎好抓，AI 也容易整段引用。
  • 小标题按买家的问题排：多用疑问句，每个小节落一个真实数据点，不写「行业领先」这类空话。
  • 配一组问答：产品页和文章页配 4–6 个买家真会问的问题，答案直给结论——买家问 AI 时问的往往就是这些。
  • 上线后看信号：第 7 天查一次收录、每月用同一组买家问题复查 AI 有没有引用本站，结论变成下一轮更新的选题。
把预期说在前面：我们看的是收录和引用信号，不承诺排名第几、流量多少——那不是任何人能打包票的事。能保证的是打法对、动作全、每月有数。
