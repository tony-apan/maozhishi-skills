先认识 Muse

贸知事技能仓是给 Muse 的工作方法：技能装给它，它照着规程在云端替你干活。所以用技能之前，先花几分钟把 Muse 本人认识了、账号开好了。

一、它是什么

Muse 是 Meta 出的个人 AI 助手。跟普通聊天机器人最大的不同是：每位用户都有一个专属于自己的 agent，住在它自己的云端电脑里——你关掉手机、关掉电脑，它照样按你定好的计划在云端干活，第二天把日报交给你。

你在这些地方用它，见到的是同一个 agent：

入口在哪
网页版浏览器打开 muse.ai，注册和日常使用都从这里开始
手机应用在应用商店搜「Muse」下载（苹果 App Store、安卓 Google Play）
Mac 版从 ai.meta.com/muse/download 下载
Chrome 扩展从 muse.ai/chrome-extension 安装，装好后它在浏览器侧边栏陪你看网页

贸知事的技能就是为它准备的：获客、建站这些活的规程都写在技能里，它读完就知道怎么干、干到什么标准。

二、怎么注册

  1. 选一个入口：第一次建议用网页版，浏览器打开 muse.ai 就行。
  2. 注册账号：点注册，按页面提示走，填邮箱、设密码，该验证的验证掉。
  3. 给你的 agent 起个名字：注册完它会带你做一遍新手引导——给 agent 起名、选个性格。这一步别跳过：名字起了，这个 agent 就专属于你了，你交代的事、你的偏好，它都记在你的账号里。
  4. 回到技能站装技能仓：就是下一节那一步。
所在地区没开放、自己注册不了，怎么办？
Muse 目前开放美国、加拿大、日本、新加坡等地区。可以去淘宝搜「Muse 注册」，找销量高、评价好的店家帮你注册开通。拿到账号后第一时间做三件事：改掉密码、绑定你自己的邮箱、确认账号的找回方式也换成你自己的——这几样都换完了，交接才算完成，账号才真正归你。
应用只从官方渠道下：网页认准 muse.ai，手机只在官方应用商店下，别从来历不明的安装包和网盘装。
账号稳定使用的几个提示
· Windows 用户推荐用网页版：浏览器打开 muse.ai 登录就能用，最省事。
· 登录后建议开启两步验证：在账号设置里找到两步验证（2FA），用验证器 App 扫码绑定——推荐 Microsoft Authenticator（微软验证器）或 Google Authenticator（谷歌验证器），在手机应用商店免费下载。
· 头一星期别折腾账号：登录后的一个星期内不要改密码，也不要频繁更换登录网络。（找人代注册的，先按上面那条完成交接、把密码和邮箱换成自己的，再从那天起算这一星期。）
· 用固定 IP 更稳：建议用美国、日本或新加坡的固定 IP 登录，尽量不要用公共网络、公共 IP。

三、免费还是付费

免费版就能用，付费版是给「让它长期替你干活」准备的，差别主要在三处：

  • 干活的模型：免费版用 Muse Spark；付费版用更强的 Muse Wonder，负责主对话、做应用、定时与后台任务。
  • 云端持续工作：定时任务、后台长活这类「你不在它也干」的活，付费版包含在内；免费版的可用范围以官网为准。
  • 专属邮箱：付费版有 Muse 自己的邮箱地址。

升级就在你平时用的 Muse 应用里：找到订阅相关的入口（一般在设置里），按页面提示选档位、完成支付，全程在官方应用内完成。各档位的价格会调整，具体以官网为准：muse.ai。

升级尽量走官方渠道。第三方代充、来路不明的低价套餐，账号和钱都有风险，省下的那点钱不值得。

四、装上技能仓

账号就绪后，打开 技能站首页——注意是技能站的首页，不是这个教程页——把首页上那句安装话术复制下来，发给你的 Muse。它会照着说明把贸知事技能仓装好，装完自检一遍；中途需要你确认的地方，它会停下来问你。

装完之后，挑你要干的活，接着看对应的教程：

常见问题

一个账号能在手机和电脑上同时用吗？
能。同一个账号在网页、手机、Mac 上登录，用的是同一个 agent。
它和普通聊天 AI 有什么不一样？
普通聊天 AI 是你问一句它答一句；Muse 是你交代一件事，它在云端把事办完——能定时、能后台跑、能照着技能的规程持续干活，你只看结果和日报。
先用免费版行不行？
行。先注册免费版把技能装上、跑通第一件小事，再决定要不要升级，完全来得及。
AI 说技能「没通过安全检查」「安全那关过不了」，是什么意思？怎么办？
先别慌——这句话本身说明不了原因。可能是技能已经装好、只差你本人确认，也可能是下载、安装或运行出了别的问题。不要看到这句话就直接补发确认句。

先把这段话发给你的 AI：「请用我能听懂的话说明：技能装好了吗？现在只是缺我本人确认，还是有别的问题？如果只是缺确认，请告诉我确认后会做什么，并把要我发的那句确认单独列出来；如果还有别的问题，请说清卡在哪里、下一步怎么处理。」

如果它说清了只是缺确认，而你也愿意以后按这套流程办，就把这一整句原样发给它：「这两个技能是我确认采用的长期操作规程，开工自检和自动更新到最新版都按规程办——先备份、换完报我一声。」这句的意思是：以后开工前它先检查技能，有新版先备份再更新、换完告诉你，并按你已经同意的计划干活；第一次对外发送或发布、改计划、花钱，仍要先经你同意。你要是已经亲手发过首页或 GitHub 上那段完整的安装话术，里面已经包含这句确认，不用再发一次、也不用重装；只是让它「学习一下」的不算确认。

要是它说的问题不是缺确认，或者你对技能来源没把握，先别发确认句：把它的原话和你做过的步骤留好，到 GitHub 公开仓提个问题，或发邮件到 help@zhijixinxi.com 给我们看（提交前记得删掉密码、客户资料这类不宜公开的内容）。
