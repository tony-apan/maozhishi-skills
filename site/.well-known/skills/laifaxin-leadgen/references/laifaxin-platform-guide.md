# 来发信平台介绍与文档地图

> 本篇是配套平台的介绍与官方文档导航。怎么干活以 [SKILL.md](../SKILL.md) 为准；平台功能与价格以 [来发信官网](https://laifa.xin) 为准（本篇整理于 2026-11-16，价格类信息变动较快，使用前在官网复核）。

## 一、来发信是什么

来发信是一个给外贸企业用的 AI 获客平台：把「找客户 → 筛客户 → 存联系人 → 发邮件 → 跟进」做成一条流水线，新手跟着走就能把开发信发出去、把询盘收回来。

- 官网：https://laifa.xin ｜ 登录入口：https://web.laifaxin.com
- 主线五步：**搜 → 筛 → 存 → 发 → 跟**，一条线走完外贸开发。
- 规模（官网口径）：全球 AI 数据库覆盖 8,800 万+ 企业、决策人邮箱/电话直达；12,000+ 外贸企业在用，覆盖 LED 照明、五金工具、箱包配饰、户外用品、智能家居、建材家居等行业。

## 二、核心能力（官网口径）

**5 种搜客方式**：有线索、没线索、找同行都有对应的搜法；其中「找相似」是丢进 1 个成交客户、滚出大批同类公司。
注：「找相似」是平台界面/AI 数据库里的功能；AI 经 Agent 接口执行时不调用 /domain/similar-list（已禁用），改走 /refine/company-list 关键词搜索（种子域名或品类词作 keyword）。

**5 项 AI 能力**：

| 能力 | 干什么 |
| --- | --- |
| 极速搜 | 听懂大白话描述，自动推演目标客群与市场 |
| 精准筛 | 逐家打 0–100 分（AI 评分），只留能成交的客户 |
| 找相似 | 从 1 个成交客户滚动找同行 |
| 自动跟 | 一次设好，自动跟进 3–12 轮、回信即停 |
| 懂回信 | 回信自动分类，高意向一眼锁定 |

**5 大引擎（平台侧）**：数据清洗（实时去重、活跃度打分）、平台服务（高并发）、邮箱验证（发前验真、压退信率）、邮件发送（海量 IP 与域名轮换、拟人化控速）、邮件追踪（打开/点击实时可见，送达、打开、点击、回信一张图看清）。

**发送保障（用群发前先懂这几条）**：营销域名与企业主域名物理隔离，群发不污染主域名；万级动态域名池轮换；AI 风控在退信/投诉触阈时自动保护；全球分布式节点按目标时区调度。所以技能里反复强调：**群发走平台优质通道，不要用自己的工作邮箱大批量群发**（会拉低自有域名信誉，正常往来邮件也会进垃圾箱）。

## 三、收费与点数（2026-11-16 官网口径）

来发信没有年费绑死：免费起步、点数随用随买。点数花在四处：

| 操作 | 单价 |
| --- | --- |
| 保存邮箱（验证有效） | 2 点/个（未知 1 点/个，无效不扣；已保存的不重复扣） |
| AI 评分 | 1 点/家 |
| 邮件群发 | 成功发送 1 点/封（发送前免费验证，无效不发不计费） |
| 邮箱验证 | 单次 ≤10 个免费，超出 1 点/个（会员每月另有免费验证次数） |

**新人权益**：平台给新用户备了些点数权益，在权益页分段领取（比如加客服领 SVIP 体验与月点数），能领多少以权益页当时显示为准，不以任何固定总数为准。会员每月还有月点数可领（个人版每月 3,000 点＋100,000 次邮箱验证），领取规则见 SKILL §1.6 与官网《新人福利 · 升级攻略》。

**付费选项（官网现行）**：200 元套餐 12,000 点（可用券）；SVIP 年费券后 399 元（原价 999）＝全年发放合计 46,000 点（发放口径：10,000 点永久到账＋开通后 12 个月内逐月发放 3,000 点、每笔月点数 30 天内有效；年费赠点平台 2026-11-19 已由 20,000 调整为 10,000）；加油包 1,000 元＝100,000 点；团队用企业版（独立体系，询客服）。价格会变，付费前以官网为准。SVIP 真正值钱的其实在搜索：每日查看从 50 次升到 500 次、每次搜索可见企业从免费版的前 30 家升到约 1 万家（免费版每搜只看前 30 家、第 4 页以后就看不了）——找客户时先卡住的通常就是这一条，点数反而不是最紧的。

## 四、文档地图（官方文档在哪、怎么组织）

来发信的官方文档就挂在官网 laifa.xin 上，按「栏目/篇目」组织，新手按编号线走、熟手按问题查专篇：

| 分区 | 内容 | 入口 |
| --- | --- | --- |
| 入门线（带编号） | 《5 分钟看懂来发信》《注册与准备》等，从认识平台到领完新人福利 | 官网指南区，从第 1 篇顺号读 |
| 功能专篇 | 联系人管理（去重保护）、邮件群发指南（扣点规则）、谷歌地图搜客等，一功能一篇 | 在官网按功能名找对应专篇 |
| 邮箱绑定系列（/youxiang/） | 各家邮箱怎么绑：[Gmail 绑定](https://www.laifa.xin/youxiang/101-guge-gmailyouxiang-google-personal-email)（两步验证＋16 位应用专用密码）、[QQ/ Foxmail 绑定](https://www.laifa.xin/youxiang/106-tengxun-qqyouxiang-tencent-personal-email)（开 IMAP/SMTP＋16 位授权码）等，含避坑表 | 精发绑自有邮箱前先查对应篇 |
| AI 获客速通（/share/ai/） | [《从零到询盘：AI 获客四步速通》](https://www.laifa.xin/share/ai/one-page-quickstart)：装工具、配模型、装 skill、跑通第一轮获客 | 想看完整链路长什么样时读 |
| 福利与点数（/zhinan/） | [《新人福利 · 升级攻略》](https://www.laifa.xin/zhinan/rights-comparison)：新人权益的领法、点数单价、四种付费方案对比 | 算账、升级前必读 |

查文档的顺序建议：先走入门线 → 干活卡住查功能专篇 → 绑邮箱查 /youxiang/ 对应篇 → 涉及点数与升级查 /zhinan/。

## 五、和本技能的关系

- 技能负责「指挥 AI 按规矩干活」：找客、评分、精发（自有邮箱，一对一）、群发跟进（平台优质通道）、台账与安全闸都在 SKILL 里。
- 平台负责「真正把事做成」：数据库、验证、发送通道、追踪都在来发信里。
- 平台规则与技能口径冲突时，先停下核对官网文档，再按 SKILL 的显名口径执行并报告。
