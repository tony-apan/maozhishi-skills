# 美观评审细则（随仓版）

建站 SKILL「美观评审关」的执行细则。评审口径与 huashu-design 的六维评审法一致：环境里装了 huashu-design skill 时可用它执行并以本文件校准口径；没装时照本文件逐项打分，结果等效。本文件随仓发布、零额外安装。

## 评审对象与时机

- 对象：全站每个页面（首页、关于、联系、产品列表、产品详情、文章列表、文章详情）＋任何单独制作的落地页；文章封面与配图走快速审。
- 时机：页面做完或改完、交付之前；建后收口的审查步必走一轮全站评审。
- 每项修复都要落到「后台哪个功能能改」上；后台确认改不了的，标为平台边界，不写成待修。

## 六维评分（每维 1–10 分，各配一句判语）

1. **概念/立意**：这一页有没有一个从用户内容里长出来的说法。盖住文字与 logo 还认得出是这家公司的站，算有概念；换个公司名也成立的，是模板套皮，本维 ≤5。
2. **哲学一致性**：全站视觉方向（一句视觉方向，默认克制、安静、可靠）是否贯彻到每一页，有没有自相矛盾的元素混进来。
3. **视觉层级**：标题与正文字号对比 ≥2.5 倍；颜色、粗细、大小建立 3–4 个清晰层级；眯眼看层级仍清楚。
4. **细节执行**：间距成系统（同类元素间距一致）、对齐精确、颜色受控（1 主色＋1 辅色＋1 强调色＋灰阶）、字体 ≤2 种、正文 ≥14px、对比度 ≥4.5:1。
5. **功能性**：每个元素都服务于买家把事办成；删掉不心疼的装饰就该删；询盘入口在该出现的阶段出现且点得通。
6. **创新性**：在平台模板边界内有没有自己的表达，避开图库感、渐变圆球一类陈词。

**风格定位（加审项，双轨判据）**：先确认本站所选风格轨（开工选定、记在 site-brief 与交接里；没记录的按默认轨外贸 B 端判），再按对应轨查串轨，细项对照 references/style-profiles.md：
- **选 B 端轨查 C 端残留**：出现 C 端消费风（生活方式种草、情绪化文案、零售促销话术、把批发站写成零售店）在概念与一致性两维扣分；参数与合作条款缺位、被场景文案挤到页面后部，在功能性扣分。
- **选 C 端轨查 B 端误入**：出现批发口径（起订量、箱规、贸易条款占据消费页面，批发黑话、把个人消费者当采购商）在概念与一致性两维扣分；只有参数堆砌、没有场景与体验表达，在概念维扣分；价格展示若出现，必须是用户真实价格（编价、演示价未清是硬伤，先清再评）。
- **两轨共同**：同一站两种口径混搭（如 B 端页面配种草文案、C 端页面收批发式询盘信息）扣一致性；与所选轨无关的元素先改回所选轨、再复审本项。

## 过关线与一票否决

- 总评（六维平均）≥8 且概念维 >5，才算过关。
- 概念维 ≤5 时总评封顶 6 分：先修概念，再谈执行，不许把模板打磨得更亮来蒙混。
- 不过关的逐项改、改完复审；评审结论记进交接文件（页面、日期、总分、最弱一项）。

## 快速审（文章封面与配图）

只看三维：视觉层级、细节执行、功能性；过关线同样 ≥8。另查硬项：不冒充产品实拍、无水印、不压字到看不清、与全站一套处理。

## 独立站常见丑点清单（先查这些）

- 模板演示品牌残留（页眉页脚、评价、新闻、悬浮钮）
- 无图占位与破图、同一张图多处复用
- 首页模块空置硬撑（评价没评价、文章没文章）
- 颜色失控：超过 4 个彩色在同屏抢通道
- 标题与正文字号太近、层级平
- 间距忽大忽小、对齐三种并存
- 页眉页脚逐页不一致（品牌名、邮箱、导航对不上）
- 按钮与链接样式全站多套
- 留白不足、信息糊成一团；或大片死白像没加载完
- 图上叠字过多、字体与全站不一致

## 输出格式（逐页一份）

```
页面：<名称与链接>
总评：X.X/10（概念 X · 一致性 X · 层级 X · 细节 X · 功能 X · 创新 X）
最弱一项：<维度与一句判语>
问题清单（按严重程度）：
1. <问题> — 当前：<实况>；修法：<具体操作与数值>；落点：<后台功能入口 / 平台边界>
快速修复（只剩 5 分钟先做这 3 件）：……
```
